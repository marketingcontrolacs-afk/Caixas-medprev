# Caixas MedPrev

Portal do Cliente da Controlacs. Site estático (index.html) publicado pelo GitHub Pages; dados e login no Supabase (com regras de acesso por usuário em todas as tabelas).

Este repositório é público. Por isso os scripts SQL do banco, que trazem dados de clientes, colaboradores e lançamentos, não ficam aqui: estão guardados na pasta do projeto (sistema-caixa/sql-versoes e sistema-caixa/para-rodar).
